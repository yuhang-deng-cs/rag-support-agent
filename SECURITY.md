# Security Policy

Tenant isolation is the core promise of this project, so isolation or authentication bugs are
treated as the highest priority.

Please **do not** open a public issue for vulnerabilities. Report them privately through
[GitHub Security Advisories](https://github.com/yuhang-deng-cs/rag-support-agent/security/advisories/new),
including steps to reproduce (ideally a failing test in `tests/test_attacks.py` style).

You can expect an initial response within 7 days. The threat model is documented in
[docs/security.md](docs/security.md).
